# Student Expense Tracker

## 1. Project Overview

A Python command-line application developed to help students record, manage and review their daily expenses.

## 2. AI Coding Assistant

GitHub Copilot (used with instructor permission).

## 3. Technologies Used

- Python 3.14.6
- Visual Studio Code
- Git
- GitHub
- Python unittest

## 4. Features

1. Add an expense.
2. Display all expenses.
3. Calculate total expenses.
4. Search expenses by category.
5. Delete an expense.
6. Generate expense summaries.
7. Validate user inputs.

## 6. Installation and Execution

Python 3.9 or newer is required.

Run the application:

```bash
python main.py
```

Run the unit tests:

```bash
python -m unittest -v
```

## 7. Prompt Engineering Techniques

### Zero-shot Prompting
Used to generate the initial application and improve the command-line interface without providing examples.

### Few-shot Prompting
Used to improve expense validation and function documentation by providing input-output examples.

### Chain-of-thought Prompting
Used to investigate edge cases, debug logical problems and review code quality through step-by-step analysis.
